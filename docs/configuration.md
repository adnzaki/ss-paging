# Configuration
There are several configurations available in SSPaging through the `getData()` method as described before. Now, let us dive into deeper part of SSPaging configuration.

## `getData()` Options
SSPaging requires 7 options to generate pagination. To maximize SSPaging's functionality, it's recommended to set as many options as possible. Below are the complete explanations of SSPaging configurations passed via the `getData()` method.

### `lang`: string
SSPaging provides 2 languages for you: English and Indonesia. Accepted values are `'indonesia'` and `'english`. In the current version, SSPaging uses English as the default language.

### `limit`: number
This option is a part of SSPaging URL pattern. It will be used to limit results generated by the backend. Default value is `10`.

### `offset`: number
This option is a part of SSPaging URL pattern. It will be used to determine where to start displaying data.

### `orderBy`: string
This option is a part of SSPaging URL pattern. It will be used to set the data order.

### `searchBy`: string|array
This option is a part of SSPaging URL pattern. It will be used to tell the server which field is used to search data. It can be a string or array.

### `sort`: string
This option is a part of SSPaging URL pattern. Common values for this option are 'ASC' and 'DESC', but it can be another value depending on your backend.

### `search`: string
This option is a part of SSPaging URL pattern. It accepts your search query parameter.

### `url`: string
This option is a part of SSPaging URL pattern. This is your main URL as described in SSPaging URL pattern, and it can be customized depending on your needs.

### `linkNum`: number
The number of page links you want to provide to users. (Eg. 1,2,3...)

### `linkClass`: string
The class style of the pagination item. It is optional; use only if you want to dynamically change the link class.

### `activeClass`: string
The current active page class style (for link numbers only).

### `disabledClass`: string <Badge type="tip" text="⚡New in v3" />
Set class for disabled links.

### `useHeader`: boolean <Badge type="tip" text="⚡New in v3" />
Set to `true` if you want to pass `limit`, `offset`, `orderBy`, and `sort` as request headers.

### `usePost`: boolean <Badge type="tip" text="⚡New in v3.0.2" />
Set to `true` if you want to pass `limit`, `offset`, `orderBy`, `sort`, `searchBy` and `search` as POST request.

### `autoReset`: number
This option allows you to automatically reset search to the default data if it meets the specified timeout.

### `delay`: number
By activating this option, SSPaging will delay search after the query has been submitted within the specified timeout.

### `token`: string
This option is used to store your token.

### `mode`: string
The mode you want to use for the request with the `fetch()` method, e.g., `cors`, `no-cors`, or `same-origin`. Default is `cors`.

### `debug`: boolean <Badge type="tip" text="⚡New in v3" />
Set to `true` to activate console debugging.

### `beforeRequest`: function
You can run something before the request is sent by defining your function in this option.

### `afterRequest`: function
You can also execute a function after a successful request by defining it in this option.

### `onError`: function <Badge type="tip" text="⚡New in v3.0.3" />
Use this option to define a custom function that handles errors and displays user-friendly messages.



## API Reference
| Method                      | Scope      | Description                                                             |
|-----------------------------|------------|-------------------------------------------------------------------------|
| `isDisabled(page: int)`     | Navigation | Determine if a first/prev/next/last link should be disabled             |
| `nav(page: int)`            | Navigation | Navigate to the given page                                              |
| `activeLink(link: int)`     | Navigation | Determine if a page link is currently active                            |
| `onSearchChanged()`         | Search     | Method to run after the search parameter has changed                    |
| `filter()`                  | Search     | Filter data based on search parameter                                   |
| `showPerPage()`             | Dropdown   | Change the number of items per page based on the selected row           |
| `sortData(orderBy: string)` | Table      | Apply sorting to the server-side data                                   |
| `reloadData()`              | Table      | Reload data based on SSPaging settings                                  |
| `itemNumber(index: int)`    | Table      | Show the item number based on its order in the data                     |
| `activePage`                | -          | Get the current active page                                             |
| `rowRange()`                | -          | Show the range of the current active data                               |

| `pageLinks`        | `number[]`                            | Array of page numbers to display                                               |
| `limit`            | `number`                              | Number of items per page                                                       |
| `offset`           | `number`                              | Starting index for current page                                                |
| `prev`             | `number`                              | Previous page number                                                           |
| `next`             | `number`                              | Next page number                                                               |
| `first`            | `number`                              | First page number                                                              |
| `last`             | `number`                              | Last page number                                                               |
| `setStart`         | `number`                              | Starting link number                                                           |
| `totalRows`        | `number`                              | Total number of records                                                        |
| `numLinks`         | `boolean`                             | Whether to show numeric links                                                  |
| `activeClass`      | `string`                              | CSS class for active page link                                                 |
| `linkClass`        | `string`                              | CSS class for normal page link                                                 |
| `disabledClass`    | `string`                              | CSS class for disabled link                                                    |
| `showPaging`       | `boolean`                             | Whether to show pagination                                                     |
| `search`           | `string`                              | Search keyword                                                                 |
| `data`             | `Array<string>`                       | Fetched data result                                                            |
| `rawResponse`      | `Array<string>`                       | Raw server response                                                            |
| `orderBy`          | `string`                              | Column name for sorting                                                        |
| `searchBy`         | `string`                              | Column name to search by                                                       |
| `sort`             | `string`                              | Sort direction (`asc` or `desc`)                                               |
| `whereClause`      | `string \| boolean \| null`           | Custom filter condition                                                        |
| `url`              | `string`                              | Data endpoint URL                                                              |
| `ascendingSort`    | `boolean`                             | Whether sorting is ascending                                                   |

| `debug`            | `boolean`                             | Show internal logs for debugging                                               |
| `errorMessages`    | `string`                              | Contains error messages                                                        |
